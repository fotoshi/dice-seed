# Requisitos — Python

- **Python 3.2 o superior.** El script usa `int.to_bytes` / `int.from_bytes`,
  disponibles desde esa versión.
- **Ninguna dependencia externa.** Solo usa `hashlib` y `sys`, de la biblioteca
  estándar.
- Viene preinstalado por defecto en macOS y en casi todas las distribuciones
  de Linux. En Windows, instálalo desde https://www.python.org/downloads/
  (o usa WSL).

Comprueba tu versión antes de empezar:

```bash
python3 --version
```

No hace falta `pip install` nada.
